# Data dictionary

Field definitions only. This document contains no record values, examples, or sample payloads.

Required means required by the immediate enclosing object when that object is present. Optional containers do not make their children globally required. Open objects allow additional fields; runtime domain validators remain authoritative.

Monetary fields use the enclosing currency. Percent and ratio are distinct units; do not interchange them. Identifier and display-name fields are supplied by the operator.
