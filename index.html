Metric Glossary — What Each Number Means
Total Runs
Number of complete deal analysis pipeline executions recorded. Each run processes one deal through all 6 AI agents.
Success Rate
Percentage of pipeline runs that completed all 6 agents without error. Failures are typically LLM timeouts or CRM connectivity issues.
Avg Latency / p95 Latency
Mean and 95th-percentile end-to-end time to run the full pipeline. p95 shows worst-case performance — 95% of runs finish faster than this.
Latency Percentiles (p50 / p90 / p95 / p99)
p50 = median run time. p90/p95/p99 are tail latencies. A large gap between p50 and p99 indicates occasional very slow runs.
Run Analysis Performance Chart
Each dot = one full 6-agent pipeline run. Blue dots are successes, red dots are failures. The yellow trend line is a rolling 10-run average showing performance drift over time.
Avg Processing Time / Avg Token Output per Agent
Two separate charts: latency shows how long each agent took (purple, horizontal); tokens shows how much text each agent generated (vertical, colour-coded per agent). Memo Writer leads both — it runs longest and writes the most.
Avg Forecast Scenarios by Risk Level
For each risk classification (LOW → CRITICAL), shows the average worst-case, expected, and best-case revenue forecast in $K. Higher risk = lower and narrower forecasts.
Assumption Refinements Before Save
How many times a user adjusted win rate or discount before accepting the forecast. Higher-risk deals tend to require more refinements as users stress-test assumptions.
CRM Fetch / Write Success Rate
Fetch = reads from Twenty CRM (deal data, contacts). Write = forecast values saved back to CRM. Any value below 95% warrants investigation of the CRM API connection.
Deals Analyzed / High-Risk Count
Unique deals that went through the full AI committee pipeline. High-Risk Count shows deals flagged HIGH or CRITICAL by the Risk Analyst — these need immediate attention.
Forecasts Written to CRM
Number of financial simulation results (worst/avg/best case + risk level) that were confirmed and saved back to Twenty CRM as deal fields.
Recent Pipeline Runs Table
The 10 most recent deal analysis runs. Shows deal name, total pipeline duration, pass/fail status, and the timestamp when the run started.
